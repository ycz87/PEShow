## 2. 视觉设计规范

### 2.1 色彩语义（全站统一，深浅主题各一套色值）

| 对象 | 颜色 | 说明 |
|---|---|---|
| 自由电子 | 亮蓝 / 青 | 粒子带轻微辉光 |
| 空穴 | 橙 / 珊瑚红 | 空心圆环，与电子形状不同，方便色弱者区分 |
| N 型区 | 淡蓝底色 | 掺杂浓度越高颜色越深：N+ > N > N- |
| P 型区 | 淡粉/淡橙底色 | 同上：P+ > P > P- |
| 电离施主 / 受主 | ⊕ / ⊖ 固定小符号 | 不移动，用来体现空间电荷 |
| 电场 | 黄色箭头场 | 箭头长度与疏密表示场强 |
| 电势 / 势垒 | 紫色曲线 | |
| 栅极 / 氧化层 / 金属 | 灰绿 / 半透明白 / 金属银 | |
| 复合事件 | 白色小闪光 | 电子与空穴相遇时出现 |

### 2.2 主题
- **深色主题**：深蓝黑渐变背景，粒子辉光明显。适合视频和暗环境。
- **浅色主题**：暖白背景，提高线条粗细和对比度。适合明亮教室的投影。
- 右上角一键切换，并记住用户的选择。

### 2.3 卡通吉祥物
- **小电子**（蓝色圆滚滚、带表情）、**小空穴**（橙色圆环、带表情）。
- 用途：讲解引导、气泡对话、步骤提示、视频片头片尾。
- 表情随情境变化：被电场推动时"冲刺"；复合时"击掌消失"；被势垒挡住时"撞墙"。
- **设置面板中可以单独关闭**。关闭后保留严肃的教学样式；粒子动画本身始终是简洁的小圆点。

### 2.4 字体与排版
- 中文用思源黑体，英文/数字用 Inter，公式用 KaTeX。全部本地打包。
- 演示模式下正文不小于 28px（以 1080p 为基准），保证教室后排看得清。

### 2.5 动效原则
- 物理过程的动画讲究"准"：速度、方向、浓度变化趋势必须正确。
- 界面过渡的动画讲究"萌"：弹性入场、轻微回弹。
- 两者分开，避免卡通效果干扰对物理过程的理解。

## 3. 内容结构

### 3.1 站点结构

```
首页（器件图谱）
 ├─ 基础篇：半导体基础 → PN结
 ├─ 不可控器件：功率二极管（含 SBD 小节 → 链接 SiC SBD）
 ├─ 半控型器件：晶闸管（含 GTO、TRIAC 小节）
 ├─ 全控型器件：功率BJT、功率MOSFET、IGBT、IGCT
 └─ 宽禁带器件：SiC、GaN
设置面板：主题｜语言｜吉祥物开关｜能带图图层｜粒子数量｜动画速度｜模式切换
```

首页做成一张"器件家族图谱"：按"控制能力 × 电压/频率等级"排布，器件之间用连线标出演化关系（如 PN结 → PiN二极管 → BJT → 晶闸管 → GTO → IGCT；MOSFET + BJT → IGBT）。

### 3.2 器件页统一布局（以 1920×1080 为基准）

```
┌────────────────────────────────────────────────────────────┐
│ 符号｜中英文名称｜一句话定位            [步骤导航 1 2 3 4 5 6] │
├──────────────────────────────────┬─────────────────────────┤
│                                  │  静态 V-I 特性             │
│   主舞台：器件剖面 + 载流子动画       │  （可拖动的工作点）          │
│   显示方式：[粒子|箭头+浓度|叠加]     │                         │
│   图层：□电场 □电势 □浓度 □能带      ├─────────────────────────┤
│                                  │  动态开关波形               │
│                                  │  （可拖动的时间游标）         │
├──────────────────────────────────┴─────────────────────────┤
│ 讲解区：一句话理解 ｜ 通俗讲解 ｜ 深入一步   [吉祥物气泡]          │
└────────────────────────────────────────────────────────────┘
```

**联动机制**（本项目的核心）：
- 在 V-I 曲线上拖动工作点 → 主舞台的偏置电压、粒子流、空间电荷区宽度、势垒高度实时变化。
- 在开关波形上拖动时间游标 → 主舞台显示该时刻器件内部的载流子分布（反向恢复、拖尾电流等过程可以逐帧查看）。
- 调整电压/门极信号 → 曲线与波形上的工作点同步移动。

### 3.3 讲解文字分三层（兼顾"详细"与"通俗"）

| 层级 | 内容 | 举例（PN结） |
|---|---|---|
| ① 一句话理解 | 一行字抓住本质 | "PN结就像一道单向闸门：正向一推就开，反向怎么推都不开（直到被击穿）。" |
| ② 通俗讲解 | 类比 + 图示，不出现公式，适合大众和视频 | 用"两个房间的人互相串门，直到墙边形成一道电荷墙"来类比扩散与内建电场 |
| ③ 深入一步 | 公式、关键参数、教材对应知识点，供本科生使用，可折叠 | 内建电势 $V_{bi}=\frac{kT}{q}\ln\frac{N_A N_D}{n_i^2}$，耗尽层宽度公式等 |

每段讲解都与动画步骤绑定：讲到哪里，动画就演示到哪里。

### 3.4 名称与符号规范
- 图形符号：按 **GB/T 4728.5（等同 IEC 60617）** 绘制。
- 文字符号与参数名：参照 **IEC 60747 系列**（如 $V_{CE(sat)}$、$V_{GE(th)}$、$V_{DRM}$、$I_{TSM}$、$Q_{rr}$、$t_{rr}$）。
- 中文术语与国标/教材常用说法对齐，英文名称使用 IEC 原文。
- 每页底部列出"名词对照表"（中/英/符号）。
- 标准中没有统一规定的符号（见第 10 节），用业界通行画法，并在页面上注明。

## 4. 各器件的演示脚本（重点场景）

| 器件 | 结构展示 | 载流子与物理过程（主舞台） | 静态 V-I | 动态开关 |
|---|---|---|---|---|
| **半导体基础** | 硅晶格、共价键 | 本征激发产生电子-空穴对；N型/P型掺杂；多子与少子；漂移与扩散 | — | — |
| **PN结** | P/N 两区剖面 | ①接触瞬间扩散 → ②形成空间电荷区与内建电场 → ③漂移与扩散动态平衡 → ④正偏：势垒降低、少子注入 → ⑤反偏：耗尽层展宽、只有微小漂移电流 → ⑥雪崩击穿 / 齐纳击穿 | 指数正向特性 + 反向饱和电流 + 击穿 | 结电容（势垒电容/扩散电容）概念 |
| **功率二极管** | PiN 结构（P+/N-/N+），与普通PN结对比 | 大注入、电导调制（N-区被载流子"淹没"、电阻骤降）；关断时存储电荷被抽出 | 正向压降、阈值电压、反向阻断 | **反向恢复**：$t_{rr}$、$Q_{rr}$、$I_{RM}$；软恢复与硬恢复对比 |
| **功率BJT** | NPN 多元胞剖面 | 发射区注入 → 基区输运 → 集电结收集；电流放大；基区宽变效应；准饱和；二次击穿 | 输出特性曲线族（截止/放大/准饱和/饱和） | 开通延迟、存储时间 $t_s$、下降时间 |
| **晶闸管** | P-N-P-N 四层三结 | 双晶体管等效模型；门极触发 → **正反馈雪崩式导通**；擎住电流与维持电流；为什么门极关不断 | 正向阻断、转折、导通、反向阻断；不同门极电流下的曲线 | 开通过程（$di/dt$）、换流关断 $t_q$ |
| **功率MOSFET** | VDMOS / 沟槽栅剖面，显示多元胞 | 栅压建立电场 → 反型层（沟道）形成 → 电子沿沟道和漂移区流动；夹断；寄生体二极管 | 转移特性 + 输出特性（截止/线性/饱和）；$V_{GS(th)}$ | 栅电荷曲线与**米勒平台**；开关能量损耗 |
| **IGBT** | 与 MOSFET 对比：增加 P+ 集电区 | MOS 沟道供电子 + P+ 注入空穴 → **电导调制**；寄生晶闸管与闩锁 | 输出特性、$V_{CE(sat)}$；与 MOSFET 曲线叠加对比 | **拖尾电流**（残余空穴逐步复合）；开通/关断损耗 |
| **IGCT** | GCT 结构 + 集成门极驱动板（3D） | GTO 回顾 → **硬驱动**：关断时把阴极电流在约 1μs 内整体转移到门极，器件像 PNP 晶体管一样关断 | 导通压降低、阻断电压高 | 关断换流过程逐帧动画；与 GTO 对比 |
| **SiC 器件** | SiC MOSFET 剖面，漂移区厚度与 Si 器件对比 | **能带对比**（Si 1.12eV vs 4H-SiC 约 3.26eV）；临界击穿场强约为 Si 的 10 倍 → 同样耐压下漂移区更薄、掺杂更高、电阻更低 | Si/SiC 导通电阻–耐压对比（单极型极限曲线） | 几乎没有拖尾电流；SiC SBD 几乎没有反向恢复 |
| **GaN 器件** | AlGaN/GaN HEMT 剖面 | 极化效应 → 异质结界面形成**二维电子气（2DEG）**；耗尽型（常通）与 p-GaN 栅增强型（常断）对比 | 输出特性；无体二极管但能反向导通 | 超快开关；$dv/dt$ 对比；"电流崩塌"现象简介（深入层） |

**能带图图层**（默认关闭）：PN结、SiC、GaN 三个页面中作用最大，其他页面也可打开。

## 5. 物理模型与"正确性"保障

### 5.1 模型选择（定性正确、量级合理）

| 显示内容 | 计算方法 |
|---|---|
| 电场、电势、空间电荷区宽度 | 耗尽层近似，泊松方程解析解（突变结；必要时线性缓变结） |
| 载流子浓度分布 | 平衡态用玻尔兹曼统计；偏置下用准费米能级 + 少子扩散方程解析解；大注入用双极扩散近似 |
| 静态 V-I | 肖克利方程 + 串联电阻 + 大注入修正；MOSFET 用平方律模型；BJT 用 Ebers-Moll 模型；晶闸管用双晶体管模型 + 增益随电流变化 |
| 动态开关 | 电荷控制模型（反向恢复、存储时间、拖尾电流）+ 等效电路瞬态计算（栅电荷、米勒平台） |
| 粒子运动 | 示意性的随机热运动 + 电场驱动漂移 + 浓度梯度扩散 + 复合/产生；**粒子的统计分布向上面的解析浓度分布靠拢**，保证"粒子画面"和"曲线"一致 |

所有材料参数（$n_i$、迁移率、禁带宽度、临界场强等）放在一个统一的参数文件里，标明数值来源。

### 5.2 正确性保障流程
1. **参考资料**：王兆安《电力电子技术》、B. J. Baliga *Fundamentals of Power Semiconductor Devices*、S. M. Sze *Physics of Semiconductor Devices*，以及主流厂商应用手册（如 Infineon、ABB/Hitachi Energy、Wolfspeed、EPC）。
2. **每个器件附一份《物理说明书》**：列出所用模型、公式、参数、做了哪些简化、动画中哪些部分是夸张示意（例如：为了看得清，粒子速度与真实值不成比例）。请您审核。
3. **单元测试**：关键计算（如 $V_{bi}$、耗尽层宽度、阈值电压）与教材例题对照，自动校验。
4. **文字审核**：讲解文字先生成中文稿给您审，定稿后再翻译成英文。
5. **示意性声明**：凡是做了夸张或简化的地方，在页面上用小图标标注"示意"，避免误导。
