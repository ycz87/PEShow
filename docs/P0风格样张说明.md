# P0 风格样张说明

样张页面就是第 0 章「PN 结」的真实页面，用来比较三套视觉风格。三套风格共用同一套物理模型和讲解内容，区别只在视觉表现。

## 怎么打开

```bash
npm run dev
```

浏览器打开终端里显示的地址（一般是 http://localhost:5173）。

## 三套风格

| 键 | 风格 | 特点 | 适合 |
|---|---|---|---|
| 1 | A 夜光晶圆 | 深色实验室，粒子发光，正向时电子和空穴的流动最"炫" | B 站视频封面和片头、暗室投影 |
| 2 | B 贴纸绘本（默认） | 粗描边、平涂色块和硬阴影，像贴纸一样，卡通感最强 | 科普视频正片、学生自学 |
| 3 | C 黑板方格 | 粉笔手绘感：深色是黑板，浅色是方格纸 | 课堂投影，最像"老师在黑板上画" |

每套风格都有深色和浅色两个主题（按 T 切换）。教室投影一般用浅色更清楚，视频用深色更出效果。

## 建议按这个顺序看

1. 点「1 接触与扩散」：看 P 区和 N 区刚接触时，载流子怎样扩散、复合，离子怎样逐渐裸露，最后形成空间电荷区和内建电场。
2. 依次点 2、3、4 步（或按 → 键）：动态平衡、正向偏置、反向偏置。观察耗尽层宽度、电场三角形和电流计的变化。
3. 拖动舞台下方的「外加电压」滑块，或拖动 V-I 曲线上的圆点，两者是联动的。
4. 切换舞台左上角的三种视图：粒子 / 箭头+浓度 / 叠加。
5. 打开图层：浓度（对数坐标，来自粒子统计）、能带（默认关闭，含准费米能级）。
6. 右上角可以切换吉祥物开关、中 / EN / 中英对照、粒子数量。

## 快捷键

| 键 | 作用 |
|---|---|
| ← → / PageUp PageDown | 上一步 / 下一步（翻页笔可直接用） |
| 空格 | 暂停 / 继续 |
| 1 2 3 | 切换风格 |
| T | 深色 / 浅色 |
| M | 吉祥物开关 |
| V | 循环切换视图 |

## 需要您确认的事

- 选定一套风格作为主风格（也可以组合，例如"B 的卡通元素 + C 的配色"）。另外两套是否还要保留成可切换的主题？
- 吉祥物「小电子」「小空穴」的形象和台词语气是否合适？
- 讲解文字的深浅：「通俗讲解」和「深入一步」两层是否合适？
- 反向恢复波形目前是示意图，P1（功率二极管）中会改为由模型计算，并与舞台动画同步。

## 已知限制（样张阶段）

- 粒子速度和势垒高度做了比例缩放，否则室温下几乎看不到粒子越过势垒。页面底部已经注明，曲线使用真实电压。
- 反向电流实际只有 pA 级，V-I 曲线中已放大示意并注明。
- 打包体积约 760 kB（gzip 后约 250 kB），后续按章节拆分加载。
